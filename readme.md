# My Music 🎵

A modern, responsive web music player built with pure HTML, CSS, and JavaScript. Experience seamless music streaming with a sleek interface that lets you explore albums, and enjoy your favorite tracks with style! 🎧



## ✨ Key Features

### Music Controls 🎮
- Full playback control (play, pause, next, previous)
- Volume control with mute option
- Progress bar with seek functionality

### Library Management 📚
- Browse music by albums and artists
- Organized collection with custom categories
  - Chill Time 🌙
  - Love Tunes 💞
  - Artist Collections (Honey Singh, Arjit Singh, A.R. Rahman)
- Beautiful album artwork display
- Detailed song information

### User Experience 🎯
- Clean and modern user interface
- Fully responsive design (mobile & desktop)
- Smooth animations and transitions
- Custom-designed SVG icons
- Easy-to-use playlist management

## 🚀 Getting Started

### Prerequisites
- A modern web browser (Chrome, Firefox, Safari, or Edge)
- Git (optional, for cloning)

### Installation
1. **Clone the repository:**
   ```bash
   git clone https://github.com/AshutoshCoder2024/My-music.git
   ```
   Or download the ZIP file and extract it

2. **Navigate to the project folder:**
   ```bash
   cd My-music
   ```

3. **Launch the app:**
   - Simply open `index.html` in your web browser
   - Or use a local server like Live Server in VS Code

## 🎨 Customization

### Adding Your Music
1. Navigate to the `Song/` directory
2. Create a new folder for your album/playlist
3. Add your MP3 files
4. Create an `info.json` with track details
5. Add a `cover.jpg` for album artwork

### Styling
- Main styles: `css/style.css`
- Utility classes: `css/utility.css`
- Colors and themes can be modified in CSS variables
